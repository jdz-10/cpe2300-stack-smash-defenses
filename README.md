# Stack Smash → Defenses

An isolated RISC-V Playground project demonstrating a controlled stack-buffer overflow and the effect of bounds checks and a stack canary. It is a classroom-only emulator demonstration; it must not be applied to real programs or systems.

## Contents

- `CPE2300-Stack-Smash-Workbook.html` — filled planning workbook and test checklist.
- `stack-smash-control-flow.svg` — system/control-flow diagram for the plan and report.

## Team setup

Replace the workbook's `TBD` fields with the two team members' names and the shared repository URL. Each student must write and be prepared to explain their own assembly code.
